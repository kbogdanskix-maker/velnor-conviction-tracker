Portfolio Reflection

Replace the optimizer page with a persistent, context-aware conversational interface — not a critique, but a thinking partner that observes the portfolio, surfaces connections to live market data and the user's own notes, and asks focused questions to help the user articulate their own reasoning.

AI approach: Reflective Analyst — opens with a data-driven observation, shares a concise read, asks one focused question. Tone calibrated to declared sophistication level.

Page Structure

Layout

  • Two-column desktop
  • 240px context panel left
  • Chat fills remaining width
  • Single-column stack on mobile

Route & nav

  • Route: /optimizer (unchanged)
  • Sidebar label: Reflect
  • Icon: Brain
  • Heading: "Reflect"

Context Panel

Everything the AI knows about you — visible so you can see its full picture. Read-only; editing lives in each respective page.

Portfolio

  • Total value, total return %
  • Sharpe, volatility, position count
  • Source: SWR summary cache

Holdings

  • Ticker + days held (from created_at)
  • Weight % + unrealised P&L %
  • Sorted by weight desc

Thesis

  • Count + teal indicator
  • "View →" → /thesis
  • Nudge note below count

Goals

  • Primary goal name + target
  • Progress bar + % funded
  • Years remaining

Profile pills

  • Risk teal
  • Sophistication teal
  • Age, tax bracket
  • Avg hold amber — behavioral gap flag

Quick Notes

  • Multi-line textarea
  • Auto-saves on blur → reflection_notes
  • Injected into every AI message

Chat

Persistence

  • Stored in useCloudStore("portfolio_reflection_chat")
  • Schema: { messages: Message[], started_at, last_active }
  • Capped at 50 messages — oldest trimmed when exceeded
  • "Clear chat" resets and triggers a new opening message

Opening message

  • Auto-generated on first load or after clear — no user action required
  • Picks the most interesting signal: quick notes × macro data, largest concentration, behavioral gap

Input

  • Multi-line textarea, grows up to 4 lines
  • Cmd+Enter / Ctrl+Enter to send — Enter adds newline
  • Disabled while AI is responding

Backend — POST /ai/reflect

Request body

{
  "messages": [{ "role": "user|assistant", "content": "..." }],
  "profile": { "age": 30, "riskTolerance": "aggressive", "sophistication": "advanced", "marginalTaxRate": 22 },
  "quick_notes": "Yields rising — thinking large banks for NIM...",
  "thesis_notes": [{ "ticker": "NVDA", "stance": "bullish", "title": "...", "body": "..." }],
  "is_opening": false
}

Backend enrichment (server-side)

  • Full holdings from DB (ticker, avg_cost_basis, quantity, created_at)
  • Enriched portfolio summary from Redis cache
  • Goals + net worth from DB
  • Macro context: 10Y yield, Fed Funds rate, VIX (existing macro service)

System prompt rules

  • Ask one question at a time — never multiple in one message
  • Keep responses under 120 words unless user asks to elaborate
  • Never tell the user they made a mistake — ask questions that help them reach their own conclusions
  • Never add generic financial advice or disclaimer boilerplate
  • When notes mention a market theme, connect it to their actual portfolio
  • Reference specific tickers and real numbers
  • Tone scales with sophistication: Advanced = institutional, Intermediate = brief explanations, Beginner = accessible

Data Flow

// Page load
→ useCloudStore loads messages, quick_notes, theses, profile
→ SWR loads portfolio summary, goals
→ if messages empty: POST /ai/reflect { is_opening: true }
→ stream opening message → append → save to cloud KV

// User sends message
→ append user message to state + cloud KV
→ POST /ai/reflect { messages: [...history], ...context }
→ stream response, append chunks live
→ on done: save final messages to cloud KV

Profile Changes

Add sophistication: "beginner" | "intermediate" | "advanced" to UserProfile in useProfile.ts. Default: intermediate. Add selector to My Profile page alongside risk tolerance.

Out of Scope

  • Rich Quick Capture Notes tab (images, links, video embeds) — separate spec
  • Proactive notifications ("yields moved, check your note") — requires background job
  • Per-holding conversation threads
